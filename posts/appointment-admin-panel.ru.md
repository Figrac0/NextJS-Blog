## 🏗️ Архитектура системы

### **Основа на TypeScript**

Построена полностью на **TypeScript**, обеспечивая безопасность типов во время компиляции и устраняя ошибки времени выполнения. Система использует строгие интерфейсы для данных записей, значений контекста и полезных нагрузок действий.

### **Кастомный слой управления состоянием**

Вместо Redux Toolkit я реализовал **кастомную Redux-подобную архитектуру** с:

- **Context API** в качестве провайдера хранилища
- **useReducer** для предсказуемых обновлений состояния
- **Строгие типы действий** с TypeScript enum
- **Синхронные обновления без middleware**

### **Архитектура потока данных**

```typescript
Запрос API → Кастомный Http хук → Диспатч действия → Редюсер → Обновление состояния → Ре-рендер UI
```

## 🔄 Дизайн управления состоянием

### **Реализация контекста записей**

Система использует сложный провайдер контекста, который обрабатывает:

- Двойное состояние записей (все записи vs активные записи)
- Фильтрацию по датам календаря с выбором диапазона
- Отслеживание статуса загрузки (idle, loading, error)
- Конвейеры трансформации данных

```typescript
// Основной интерфейс контекста
interface AppointmentContextValue extends IAppointmentState {
    getAppointments: () => void;
    getActiveAppointments: () => void;
    setDateAndFilter: (newDate: Value) => void;
}

// Редюсер состояния со строгими типами действий
export enum ActionsTypes {
    SET_ACTIVE_APPOINTMENTS = "SET_ACTIVE_APPOINTMENTS",
    SET_ALL_APPOINTMENTS = "SET_ALL_APPOINTMENTS",
    FETCHING_APPOINTMENTS = "FETCHING_APPOINTMENTS",
    ERROR_FETCHING_APPOINTMENTS = "ERROR_FETCHING_APPOINTMENTS",
    SET_CALENDAR_DATE = "SET_CALENDAR_DATE",
}
```

---

### **Система фильтрации данных**

Контекст включает интеллектуальную фильтрацию, которая:

- Фильтрует записи на основе выбранных диапазонов дат календаря
- Отделяет активные записи от отмененных
- Обрабатывает граничные случаи для частичного выбора дат
- Сохраняет целостность данных во время операций фильтрации

## 🎯 Ключевые технические решения

1. **Кастомное управление состоянием** вместо Redux Toolkit для лучшего контроля и меньшего размера бандла
2. **TypeScript strict mode** для предотвращения ошибок времени выполнения и улучшения опыта разработки
3. **Кастомный HTTP хук** вместо axios для HTTP запросов без зависимостей
4. **SCSS Modules** вместо styled-components для лучшей производительности и контроля CSS
5. **Day.js** вместо Moment.js для меньшего размера бандла и современного API
