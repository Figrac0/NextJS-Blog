## 🔐 Система аутентификации

### **Конфигурация Lucia**

Сердце системы аутентификации - Lucia Auth, настроенная для оптимальной безопасности:

```javascript
import { Lucia } from "lucia";
import { BetterSqlite3Adapter } from "@lucia-auth/adapter-sqlite";

// Конфигурация адаптера базы данных
const adapter = new BetterSqlite3Adapter(db, {
    user: "users",
    session: "sessions",
});

// Экземпляр Lucia с настройками безопасности
const lucia = new Lucia(adapter, {
    sessionCookie: {
        expires: false, // Истечение сессии браузера
        attributes: {
            secure: process.env.NODE_ENV === "production", // Только HTTPS в production
            sameSite: "lax", // Защита от CSRF
        },
    },
    getUserAttributes: (attributes) => {
        return {
            email: attributes.email,
            createdAt: attributes.created_at,
        };
    },
});
```

## Безопасность паролей

Безопасная обработка паролей с использованием Node.js crypto:

```javascript
export function hashUserPassword(password) {
    // Генерация уникальной 16-байтной соли для каждого пользователя
    const salt = crypto.randomBytes(16).toString("hex");

    // Scrypt: memory-hard функция получения ключа
    const hashedPassword = crypto.scryptSync(password, salt, 64);

    // Хранение в формате "хеш:соль" для верификации
    return hashedPassword.toString("hex") + ":" + salt;
}

export function verifyPassword(storedPassword, suppliedPassword) {
    const [hashedPassword, salt] = storedPassword.split(":");

    // Воссоздание хеша с теми же параметрами
    const suppliedPasswordBuf = crypto.scryptSync(suppliedPassword, salt, 64);
    const hashedPasswordBuf = Buffer.from(hashedPassword, "hex");

    // Сравнение с защитой от атак по времени предотвращает атаки по времени
    return crypto.timingSafeEqual(hashedPasswordBuf, suppliedPasswordBuf);
}
```

## 🎯 Ключевые компоненты

### **Компонент формы аутентификации**

Форма аутентификации обрабатывает и вход, и регистрацию с валидацией в реальном времени:

```javascript
export function AuthForm({ mode }) {
    const [errors, setErrors] = useState({});
    const [isLoading, setIsLoading] = useState(false);

    const handleSubmit = async (formData) => {
        setIsLoading(true);

        // Клиентская валидация
        const validationErrors = validateForm(formData);
        if (Object.keys(validationErrors).length > 0) {
            setErrors(validationErrors);
            setIsLoading(false);
            return;
        }

        try {
            // Server action для аутентификации
            const result = await authenticate(mode, formData);

            if (result.success) {
                // Перенаправление в защищенную область
                router.push("/training");
            } else {
                setErrors(result.errors);
            }
        } catch (error) {
            setErrors({ general: "Произошла непредвиденная ошибка" });
        } finally {
            setIsLoading(false);
        }
    };

    return (
        <form onSubmit={handleSubmit}>
            <Input
                name="email"
                type="email"
                placeholder="user@example.com"
                error={errors.email}
                required
            />
            <Input
                name="password"
                type="password"
                placeholder="••••••••"
                error={errors.password}
                required
            />
            <Button type="submit" disabled={isLoading}>
                {isLoading
                    ? "Обработка..."
                    : mode === "login"
                      ? "Войти"
                      : "Создать аккаунт"}
            </Button>
        </form>
    );
}
```

### **Middleware защищенных маршрутов**

Middleware, который защищает маршруты и валидирует сессии:

```javascript
export async function middleware(request) {
    const sessionId = request.cookies.get(lucia.sessionCookieName)?.value;

    if (!sessionId) {
        // Нет сессии - перенаправление на вход
        return NextResponse.redirect(new URL("/login", request.url));
    }

    try {
        // Валидация сессии с Lucia
        const { session, user } = await lucia.validateSession(sessionId);

        if (!session || !user) {
            // Невалидная сессия - перенаправление на вход
            return NextResponse.redirect(new URL("/login", request.url));
        }

        // Валидная сессия - продолжить
        const response = NextResponse.next();

        // Обновить сессию если нужно
        if (session.fresh) {
            const sessionCookie = lucia.createSessionCookie(session.id);
            response.cookies.set(
                sessionCookie.name,
                sessionCookie.value,
                sessionCookie.attributes,
            );
        }

        return response;
    } catch (error) {
        // Ошибка валидации сессии
        return NextResponse.redirect(new URL("/login", request.url));
    }
}
```

## 🎯 Справочник API

### **Server Actions**

#### **`authenticate(mode, formData)`**

Обрабатывает операции входа и регистрации.

**Параметры:**

- `mode`: `"login"` | `"signup"`
- `formData`: Данные формы с email и паролем

**Возвращает:**

- `{ success: boolean, errors?: object, user?: object }`

#### **`logout()`**

Завершает текущую сессию пользователя.

**Возвращает:** Перенаправление на страницу входа

---

### **Функции базы данных**

#### **`createUser(email, password)`**

Создает нового пользователя с хешированным паролем.

**Параметры:**

- `email`: Email адрес пользователя
- `password`: Пароль в открытом виде

**Возвращает:** Объект пользователя с ID и email

#### **`getUserByEmail(email)`**

Получает пользователя по email адресу.

**Параметры:** `email`: Email для поиска

**Возвращает:** Объект пользователя или `null`

---

### **Утилиты аутентификации**

#### **`verifyAuth()`**

Валидирует текущую сессию и возвращает пользователя.

**Возвращает:** `{ user: User | null, session: Session | null }`

#### **`requireAuth()`**

Валидирует сессию и выбрасывает ошибку если не аутентифицирован.

**Выбрасывает:** Перенаправление на вход если не аутентифицирован
