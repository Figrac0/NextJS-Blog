## 🎯 Обзор проекта

ReactQuiz — это интерактивное квиз-приложение, демонстрирующее современные паттерны разработки на React с использованием исключительно встроенных возможностей библиотеки. Приложение последовательно отображает вопросы с ограничением по времени, требуя от пользователя выбрать ответ до истечения таймера. Каждое взаимодействие иллюстрирует продвинутое управление состоянием, синхронизацию визуальной обратной связи и композицию компонентов — без сторонних библиотек управления состоянием.

Проект делает акцент на чистом, предсказуемом и реактивном дизайне, где все переходы, задержки и проверки корректности реализованы через хуки React.

## ✨ Ключевые возможности

### Пошаговый поток квиза

Вопросы появляются последовательно с автоматическим переходом либо после выбора ответа, либо по истечении времени. Это обеспечивает плавный и непрерывный пользовательский опыт, в котором состояние приложения полностью управляет логикой.

### Динамический компонент таймера

Компонент `QuestionTimer` управляет логикой обратного отсчета и инициирует событие пропуска вопроса при истечении времени. Он демонстрирует точную синхронизацию времени с циклом рендеринга React.

### Визуальные переходы состояний

Ответы проходят через несколько визуальных состояний:

- `answered` — ответ выбран, но еще не проверен
- `correct` / `wrong` — отображение результата проверки
- Следующий вопрос — автоматический переход после короткой задержки

Эти переходы синхронизированы через вложенные `setTimeout` внутри хуков `useEffect`.

### Умная валидация ответов

Корректность ответа определяется динамически на основе данных вопроса. Приложение сравнивает выбранный ответ с правильным, сохраненным в структуре данных вопроса.

### Оптимизированная рандомизация ответов

Варианты ответов перемешиваются один раз на вопрос с использованием `useRef` для кэширования массива, что предотвращает лишние перерендеры при обновлении таймера.

### Детализированная панель статистики

Компонент `Summary` анализирует историю ответов и отображает вычисленные проценты пропущенных, правильных и неправильных ответов, предоставляя наглядную оценку результатов пользователя.

### Модульная архитектура компонентов

Приложение построено на чистой и понятной структуре компонентов:

- `App` — контейнер общего макета приложения
- `Header` — отображение логотипа и заголовка
- `Quiz` — основной менеджер логики прохождения квиза
- `Question` — обработка выбора и проверки ответа
- `Answers` — рендер вариантов ответа с визуальной обратной связью
- `QuestionTimer` — логика таймера и обратного отсчета
- `Summary` — аналитика и итоговые результаты

## 🛠️ Техническая реализация

### Стратегия управления состоянием

Приложение использует комбинацию локального состояния компонентов и поднятого состояния для управления логикой квиза:

```javascript
// Из Quiz.jsx — основное управление состоянием
const [userAnswers, setUserAnswers] = useState([]);
const activeQuestionIndex = userAnswers.length;
const quizIsComplete = activeQuestionIndex === QUESTIONS.length;
```

### Логика синхронизации таймера

Компонент `QuestionTimer` использует два отдельных хука `useEffect`:

- первый отвечает за обработку тайм-аута и вызов колбэка при истечении времени
- второй управляет визуальным индикатором прогресса, обновляя оставшееся время с фиксированным интервалом

```javascript
// Из QuestionTimer.jsx
useEffect(() => {
    const timer = setTimeout(onTimeout, timeout);
    return () => clearTimeout(timer);
}, [timeout, onTimeout]);

useEffect(() => {
    const interval = setInterval(() => {
        setRemainingTime((prev) => prev - 100);
    }, 100);
    return () => clearInterval(interval);
}, []);
```

### Состояния ответа

Компонент `Question` управляет сложными переходами состояния ответа с помощью последовательных тайм-аутов. Это позволяет поэтапно отображать выбор ответа, результат проверки и автоматический переход к следующему вопросу.

```javascript
// Из Question.jsx — логика обработки ответа
if (answer.selectedAnswer) {
    timer = 1000;
}

if (answer.isCorrect !== null) {
    timer = 2000;
}

function handleSelectAnswer(answer) {
    setAnswer({ selectedAnswer: answer, isCorrect: null });

    setTimeout(() => {
        setAnswer({
            selectedAnswer: answer,
            isCorrect: QUESTIONS[index].answers[0] === answer,
        });
        setTimeout(() => {
            onSelectAnswer(answer);
        }, 2000);
    }, 1000);
}
```

## 🏗️ Архитектура и принципы проектирования

### Переинициализация компонентов через key

Компонент таймера получает динамический проп `key={timer}`, который заставляет React полностью перемонтировать компонент при изменении значения таймера. Это гарантирует корректный сброс таймера между вопросами и предотвращает утечки состояния.

### Полностью декларативная логика

UI всегда формируется исключительно на основе состояния компонентов. При любом изменении состояния React автоматически пересчитывает и перерисовывает соответствующие части интерфейса без ручного управления DOM.

### Stateless-родитель, stateful-дочерние компоненты

Основной компонент `Quiz` координирует поток данных через пропсы, сохраняя минимальное собственное состояние. Дочерние компоненты, такие как `Question`, инкапсулируют сложную внутреннюю логику и управление переходами состояний.

### Отсутствие глобального хранилища

Каждый компонент управляет своим жизненным циклом и поведением автономно, без использования Redux, Context API или других глобальных стореджей. Это снижает связанность и упрощает понимание кода.

### Детерминированный рендеринг

Одинаковые входные данные всегда приводят к одинаковому визуальному и логическому результату. Такой подход делает приложение предсказуемым, стабильным и удобным для отладки.

### Четкое разделение ответственности

Логика таймера, рендеринг вопросов и проверка ответов реализованы как независимые, переиспользуемые модули с четко определенными интерфейсами взаимодействия.

## 📚 Образовательная ценность

ReactQuiz является наглядным учебным примером для изучения:

- state-driven рендеринга в React-приложениях
- управления логикой через хуки `useState`, `useEffect`, `useCallback`, `useRef`
- паттернов взаимодействия компонентов через пропсы и колбэки
- асинхронных переходов состояния в сложных UI
- оптимизации производительности с помощью `useRef`

Кодовая база демонстрирует практическую реализацию таймированных пользовательских взаимодействий, синхронизированных переходов состояния и условного рендеринга с использованием идиоматичного современного React.
