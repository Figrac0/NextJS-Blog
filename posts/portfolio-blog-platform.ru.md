## 🚀 Обзор проекта

Это сложная, полнофункциональная платформа портфолио и блога на Next.js, которая служит одновременно личным портфолио и техническим блогом. - **Витрина портфолио** для проектов и технических статей
- **Многоязычный блог** с поддержкой английского и русского языков

### **1. Интеллектуальная многоуровневая система фильтрации**

#### **Динамическое обнаружение контента**

Платформа включает сложную систему фильтрации, позволяющую пользователям находить контент по нескольким измерениям:

```javascript
// Многомерная фильтрация с мемоизацией
const filteredContent = useMemo(() => {
    let filtered = [...formattedPosts];

    // 1. Фильтрация по категориям (проекты, туториалы, статьи)
    if (activeTab !== "all") {
        const typeMap = {
            repositories: "project",
            tutorials: "tutorial",
            insights: "article",
        };
        filtered = filtered.filter((item) => item.type === typeMap[activeTab]);
    }

    // 2. Фильтрация по технологическому стеку
    if (selectedTech !== "all") {
        filtered = filtered.filter(
            (item) => item.tech && item.tech.includes(selectedTech),
        );
    }

    // 3. Ранжирование контента с пользовательской системой оценки
    if (sortBy === "popular") {
        filtered.sort((a, b) => {
            const aScore = (a.stats?.stars || 0) + (a.featured ? 50 : 0);
            const bScore = (b.stats?.stars || 0) + (b.featured ? 50 : 0);
            return bScore - aScore;
        });
    }

    return filtered;
}, [activeTab, selectedTech, sortBy, formattedPosts]);
```

## 🎯 Ключевые технические решения

### **1. Next.js вместо других фреймворков**

**Почему был выбран Next.js:**

- **Гибкость SSG/SSR**: Идеальный баланс для контент-ориентированных сайтов
- **Встроенные оптимизации**: Оптимизация изображений, шрифтов и скриптов из коробки
- **API-маршруты**: Упрощенный бэкенд без отдельного сервера
- **Файловая маршрутизация**: Интуитивная и поддерживаемая структура
- **Интеграция с Vercel**: Бесшовное развертывание и превью

### **2. Пользовательское i18n решение вместо библиотек**

**Преимущества пользовательской реализации:**

- **Размер бандла**: Нулевые дополнительные зависимости
- **Гибкость**: Пользовательские функции перевода и форматирования
- **Контроль**: Полный контроль над стратегиями загрузки и кэширования
- **Простота**: Никакой сложной конфигурации или runtime-оверхеда
- **Поддерживаемость**: Легко отлаживать и расширять

### **3. Markdown вместо Headless CMS**

**Преимущества файлового контента:**

- **Версионный контроль**: Весь контент отслеживается в Git
- **Опыт разработчика**: Знакомый workflow для технических писателей
- **Производительность**: Никаких запросов к базе данных для доставки контента
- **Портативность**: Легко мигрировать, делать бэкап или экспортировать
- **Стоимость**: Никаких постоянных подписок на CMS

### **4. CSS Modules вместо CSS-in-JS**

**Техническое обоснование:**

- **Производительность**: Никакого runtime-оверхеда на инъекцию CSS
- **Изоляция**: Автоматическая генерация имен классов предотвращает конфликты
- **Поддерживаемость**: Совмещенные стили с четким разделением
- **Предсказуемость**: Стандартный CSS с преимуществами модулей
