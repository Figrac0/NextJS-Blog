# Многоуровневый QA Pipeline для Full-Stack приложений

Full-stack проект, ориентированный на системное тестирование программного обеспечения на нескольких уровнях приложения.  
Репозиторий объединяет backend и frontend разработку с акцентом на качество верификации, дизайн тестов, автоматизацию и воспроизводимость.

Основное приложение представляет собой вычислительное ядро с поддержкой нескольких систем счисления.  
Главный фокус проекта - это комплексный пайплайн тестирования, включающий:

- unit тестирование
- интеграционное тестирование
- BDD тестирование
- API тестирование
- нагрузочное тестирование
- frontend unit тестирование
- end-to-end тестирование

## 🏗️ Обзор архитектуры

Проект организован как многоуровневая система, объединяющая backend и frontend приложения с интегрированной инфраструктурой тестирования.

```text
automate-testing/
│
├── back/        → Spring Boot backend + уровни тестирования
├── client/      → Angular frontend + Cypress тесты
└── QA layers    → Postman, JMeter, Cucumber, Testcontainers
```

Репозиторий структурирован таким образом, чтобы отражать реальные QA-процессы, где различные инструменты тестирования работают на разных уровнях системы.

## 🎯 Фокус проекта

Проект демонстрирует структурированный подход к обеспечению качества программного обеспечения в различных областях:

- backend unit тестирование
- интеграционное тестирование backend с реальной базой данных
- behavior-driven тестирование (BDD)
- API тестирование
- нагрузочное и производительное тестирование
- frontend unit тестирование
- end-to-end тестирование

Основной акцент сделан не на бизнес-логике, а на том, насколько полно и корректно система протестирована.

## 🧪 Архитектура тестирования

Проект построен как последовательность этапов, где каждый добавляет новый уровень тестирования.

### 1. Backend Unit Testing

Фокус:

- изолированная проверка бизнес-логики
- корректность вычислений
- обработка исключений

Техники:

- параметризованные тесты
- CSV наборы данных
- динамические тесты
- вложенные тестовые классы

---

### 2. Integration Testing

Фокус:

- взаимодействие между слоями приложения
- проверка базы данных
- моделирование реальной среды

Практики:

- Testcontainers
- PostgreSQL
- Flyway миграции
- JSON фикстуры

---

### 3. BDD Testing (Cucumber)

Фокус:

- сценарии, понятные бизнесу
- исполняемые спецификации

Особенности:

- Gherkin синтаксис
- step definitions
- таблицы сценариев
- переиспользуемая подготовка

---

### 4. API Testing (Postman)

Фокус:

- независимая проверка API
- воспроизводимость запросов

Особенности:

- коллекции
- окружения
- автоматические проверки

---

### 5. Performance Testing (JMeter)

Фокус:

- стабильность системы под нагрузкой
- поведение ответов

Метрики:

- throughput
- latency
- поведение при параллельных запросах

---

### 6. Frontend Unit Testing (Angular)

Фокус:

- проверка логики UI
- изоляция компонентов

Покрытие:

- компоненты
- директивы
- пайпы
- логика валидации

---

### 7. End-to-End Testing (Cypress)

Фокус:

- реальное взаимодействие пользователя
- полный пользовательский сценарий

Особенности:

- автоматизация браузера
- паттерн Page Object
- сценарное тестирование

Запуск:

```bash
npm run cypress:open
```

## 📊 QA стратегия

Проект использует многоуровневый подход к тестированию:

- unit тесты → проверка логики
- integration тесты → проверка взаимодействия
- BDD → проверка поведения
- API тесты → проверка контрактов
- нагрузочные тесты → проверка стабильности
- frontend тесты → проверка UI логики
- E2E тесты → проверка пользовательских сценариев

Это снижает слепые зоны и повышает надежность системы.
